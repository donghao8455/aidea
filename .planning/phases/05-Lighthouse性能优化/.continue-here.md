|---------|-------------|----------|---------------------|
| Dev vs Prod 差异 | Dev 热重载掩盖真实性能问题，CLS 在 dev 未改善不代表生产无效 | blocking | 必须 `npm run build` + `serve build` 后再跑 Lighthouse |
